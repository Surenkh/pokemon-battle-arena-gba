Adaptations: extraction of the right-facing row (or the single authored direction), nearest-neighbour sizing into 64×64 cells, body-center/foot alignment, fitting compact squeeze frames to the ten-pixel hurtbox, GBA palette conversion, and synchronizing source attack impact/recovery poses with this game's frame data. No new body poses were generated for this update.

The four additions were retrieved on 3 November 2026 at the same pinned revision. `expansion_sources.json` records file hashes and `source_manifest.json` records explicit clip mappings. Gastly reuses authored poses for missing states; Riolu uses SpAttack for Shoot. Normal builds use the included files without network access.
