# Distribution

The repository contains the editable native project, required source assets, engine sources/notices, tools, tests, and playable ROM. Build with tools/build.py as described in BUILDING.md. Compiler binaries are not bundled. Historical browser-preview exports and unused optional artwork are omitted; they are not native build inputs.

The v0.3.0 elemental-attack update was merged through PR #1. The v0.4.0 combat feedback update is developed on feat/combat-feel. Update the ROM and downloads/SHA256SUMS.txt together after native validation. A dedicated GitHub Release has not been created. For a tagged release, use docs/releases/v0.4.0.md as the release text, attach downloads/PokemonBattleArena.gba and its checksum, and use tag v0.4.0 after the feature PR is merged. The connected tools support Git content updates rather than release-asset publication.

The cover is promotional art. .github/social-preview.jpg must be uploaded separately in repository Settings to configure the social preview.
