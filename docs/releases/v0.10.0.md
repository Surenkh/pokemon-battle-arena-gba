# Pokémon Battle Arena v0.10.0 — Clear Navigation

Press Select on any fighter card to open settings directly. A check keeps your
chosen Pokémon visible while the gold outline moves between settings. B returns
to the same card. These controls work in Quick Battle, Arcade and Practice.

Fighter Info is now a visible settings row. A opens its guide and B restores the
row that opened it. A/Start plays from cards or value rows, and Start also plays
from Info. Up/Down chooses a setting and Left/Right changes its value. Arcade's
rotating arena is informational and the cursor skips it.

The mode menu groups its play choices. Pause, Audio and results use a consistent
focus border and caret, and Change gets the sole active result highlight when
selected. With no Arcade continues left, Rematch is dimmed and skipped. A on the
final loss screen finishes the run.
