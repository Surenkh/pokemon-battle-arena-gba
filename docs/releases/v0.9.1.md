# Pokémon Battle Arena v0.9.1 — Responsive Firing

Normal shots show an immediate windup for Pikachu, Squirtle, Meowth, Psyduck and
Machop. These fighters use an existing authored charge pose while preparing B,
then their firing animation at release. Every fighter visibly acknowledges an
eligible tap by the second emulator frame in the measured replays.

The Fighter Mastery menu description fits inside the display, and the controls
in the README and player ZIP include the Practice Arena row.

## Verification

A new native response suite measures 90 one-frame taps against matched idle
replays across all nine fighters. It checks projectile/super release timing,
held B, rejected shots and every menu description's side margins. All ten native
suites passed with 14,042 checks and zero missed display frames. Nine host suites
and the art/audio asset checks also passed. The 4,860-round balance replay exactly
matches v0.9.0, and a separate clean build regenerates the same inputs and ROM.

Human cue recognition and physical GBA/controller latency remain to be tested.
See [response validation](../RESPONSIVE_FIRING_TEST_REPORT.md) and the
[product roadmap](../development/ROADMAP.md).
