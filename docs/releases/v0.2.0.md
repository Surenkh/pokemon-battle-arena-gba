# Pokémon Battle Arena v0.2.0 — Movement Update

A native GBA fighter with six Pokémon, animated movement, stamina-based combat, CPU rivals, and charged supers.

- Pikachu, Charmander, Squirtle, Bulbasaur, Eevee, and Meowth.
- Acceleration, braking, air momentum, and hit/landing reactions.
- Block, fire, jump, and squeeze; land hits to charge a super.
- Supers bypass block and can be evaded by jumping or squeezing.
- Character selection, battles, and result screens.

Download `PokemonBattleArena.gba` and load it in a GBA emulator. Use the in-game help for controls. Verify the ROM using `SHA256SUMS.txt`.

This release package contains the playable ROM; editable game source is not included. Physical GBA hardware and non-Linux rebuilding remain unverified. Unofficial fan project; Pokémon belongs to its respective owners.

This file records version notes. Download the ROM from `downloads/` in the repository; it is not a GitHub Release publication receipt.
