# Pokémon Battle Arena v0.3.0 — Elemental Attacks

Six fighters now have distinct animated electricity, flame, water, leaf, star, and claw attacks. Muzzle flashes, impacts and blocked-hit effects match the attacker. Thirty effect sheets contain 120 frames.

Fixes a nearly empty HUD bar rounding to zero scale. Combat balance, movement, CPU decisions and super evasion remain unchanged. The editable native project, required source assets, engine notices, tools and tests are now in Git. See docs/ELEMENTAL_ATTACKS_TEST_REPORT.md for evidence and limits. Physical GBA hardware and non-Linux rebuilding remain unverified.
