# Pokémon Battle Arena v1.0.0-rc.1 — Release Candidate 1

RC1 prepares the nine-fighter game for v1.0 validation. Records now uses fixed
background labels and redraws only the changing fighter, difficulty and values.
This removes the previous near-budget Records spike when browsing fighters.
Numbers align in a clear value column, including maximum saved counters/times.

The same full Arcade replay peaks at 86.4013671875% of a frame, down from
99.609375%. The new Records/Mastery/audio stress journey peaks at 75.71%, with
Records redraws at 41.50%. All tested journeys have zero missed display frames.

## Validation

All 14 native suites pass with 16,554 checks, along with 11 host suites,
art/audio checks, 90 response trials, the unchanged 4,860-match balance probe,
10 release integrity tests and release packaging. An independent clean build
reproduces the exact tested ROM. Legacy save migration, power cycles, corruption
fallback, interrupted writes, Practice retry boundaries and mastery exclusion
remain covered.

RC1 is a prerelease and does not replace the latest stable v0.12.0 download.
Player pilots, human matchup review and physical GBA/controller testing remain
open before final v1.0. See [candidate evidence](../V1_RELEASE_CANDIDATE_TEST_REPORT.md)
and [remaining release tasks](../V1_RELEASE_CHECKLIST.md).
