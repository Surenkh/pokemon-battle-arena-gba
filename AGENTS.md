# Project workflow

The owner authorizes implementing requested versions in this repository,
committing and pushing completed, validated changes to feature branches, and
opening pull requests automatically. Do not ask for this permission again for
each version. Keep merging with the owner unless they explicitly request a merge.

Use the normal GitHub repository Surenkh/pokemon-battle-arena-gba. Preserve old
releases and unrelated work. Follow CONTRIBUTING.md, validate the actual ROM,
update its checksum and evidence together, and include a working player ZIP
link in the PR. Prefer a verified GitHub download link for playable builds.
